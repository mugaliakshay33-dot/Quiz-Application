# Python Quiz Application

## Project Description

The **Python Quiz Application** is a simple, interactive, command-line quiz game developed using Python. It tests users' basic Python programming knowledge through multiple-choice questions.

The application displays questions with four options, checks the user's answers, calculates the total score, and displays the final percentage.

This project is ideal for beginners who want to practice Python fundamentals such as lists, dictionaries, loops, functions, and conditional statements.

## Features

* Interactive multiple-choice quiz
* Four options for each question
* Automatic answer verification
* Instant feedback for correct and incorrect answers
* Displays correct answers for wrong responses
* Calculates total score and percentage
* Simple and beginner-friendly interface
* No external libraries required

## Technologies Used

* **Programming Language:** Python 3
* **IDE:** VS Code / PyCharm / IDLE

## ⚙️ How It Works

1. The program stores questions, options, and correct answers in a list of dictionaries.
2. A `for` loop displays each question and its options.
3. The user selects an answer (A, B, C, or D).
4. The program compares the answer with the stored correct answer.
5. Each correct answer increases the score by one.
6. After all questions, the program displays the final score and percentage.
